# SystemAudit
1. Giới thiệu
Script Lấy Thông Tin Máy Tính (SystemAudit): hỗ trợ lấy thông tin máy tính phục vụ chuyển đổi số trong cơ quan, chỉ hỗ trợ hiển thị một số thông tin cơ bản, không quá chuyên sâu. Sử dụng Script sẽ an toàn, không bị cảnh báo virus hay các phiền toái khác khi triển khai cho người dùng không có nhiều kiến thức về công nghệ.
Hỗ trợ Windows 10/11.
2. Cách sử dụng
   - Đặt 2 file: SystemAudit.ps1 và Run-SystemAudit.bat cùng thư mục
   - Chạy file Run-SystemAudit.bat với quyền Admin
