# SystemAudit
Script Lấy Thông Tin Máy Tính (SystemAudit): hỗ trợ lấy thông tin máy tính phục vụ chuyển đổi số trong cơ quan, chỉ hỗ trợ hiển thị một số thông tin cơ bản, không quá chuyên sâu
Hỗ trợ Windows 10/11.
